# Reconcile concepts

Agents capturing different features of the same codebase each defined some of the same concepts, in different words. Each concept below has every definition it was given, and the functional specs that use it. Give each concept one definition that serves every one of those uses: one plain sentence that starts with the concept and says what it is, with the attributes the specs rely on. Use only the concepts listed with it. Call `submit_capture_concepts` once, with a definition for every concept.
